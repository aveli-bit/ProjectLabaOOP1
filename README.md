# ProjectLabaOOP1

Лабораторные работы №1 и №2 по объектно-ориентированному программированию на C++: система управления складом и заказами.

## Сборка и запуск

1. Открыть `ProjectLabaOOP1.sln` в Visual Studio 2022.
2. Установить компонент «Разработка классических приложений на C++», инструментарий MSVC v143 и Windows SDK.
3. Выбрать конфигурацию `Release` и платформу `x64`.
4. Собрать решение и запустить `ProjectLabaOOP1`.

## Лабораторная работа №1

- Абстрактный `Product` и категории `Electronics`, `Clothing`, `Food`.
- Товары `Smartphone`, `Laptop`, `TShirt`, `Jacket`, `Milk`, `Bread` и шесть фабрик.
- Атрибуты `Price`, `Quantity`, `Weight` с проверкой значений.
- `Warehouse` с глубоким копированием, правилом пяти и переносом товаров.
- Собственные обычный и константный итераторы.
- `LoggingProxy` для регистрации операций.
- Демонстрационные сценарии и проверки ошибок в `main.cpp`.

## Лабораторная работа №2

- `ProductType` и паттерн «Легковес» для общих характеристик товаров.
- `Order` с позициями заказа доставкой акциями и проверкой переходов статуса.
- Три способа доставки: курьер самовывоз и почта.
- Четыре акции: процентная скидка cashback бесплатная доставка и подарок.
- Паттерн «Стратегия» через интерфейсы `Delivery` и `Discount`.
- `DeliveryProxy` с проверкой региона и веса логированием и кэшем стоимости.
- Паттерн «Наблюдатель» через `IObserver` и `IObservable`.
- `OrderManager` с лимитами активных заказов учётом клиентов оборота за период и бонусного баланса.
- Операторы `order + discount` и `delivery << order` и вывод заказа через `std::ostream`.
- Глубокое копирование и перемещение заказов и менеджера с восстановлением подписок.
- Позиции заказа доступны снаружи только для чтения через `shared_ptr<const Product>`.

Примеры второй работы находятся в `main.cpp` в том числе в функциях `demonstrateOrderManager` и `demonstrateCopyAndMove`.

Исходники находятся в папке `ProjectLabaOOP1`. Служебные файлы Visual Studio и результаты сборки исключены из Git.
