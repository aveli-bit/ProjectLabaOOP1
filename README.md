# ProjectLabaOOP1

Лабораторная работа по объектно-ориентированному программированию на C++: система управления складом.

## Сборка и запуск

1. Открыть `ProjectLabaOOP1.sln` в Visual Studio 2022.
2. Установить компонент «Разработка классических приложений на C++», инструментарий MSVC v143 и Windows SDK.
3. Выбрать конфигурацию `Release` и платформу `x64`.
4. Собрать решение и запустить `ProjectLabaOOP1`.

## Состав

- Абстрактный `Product` и категории `Electronics`, `Clothing`, `Food`.
- Товары `Smartphone`, `Laptop`, `TShirt`, `Jacket`, `Milk`, `Bread` и шесть фабрик.
- Атрибуты `Price`, `Quantity`, `Weight` с проверкой значений.
- `Warehouse` с глубоким копированием, правилом пяти и переносом товаров.
- Собственные обычный и константный итераторы.
- `LoggingProxy` для регистрации операций.
- Демонстрационные сценарии и проверки ошибок в `main.cpp`.

Исходники находятся в папке `ProjectLabaOOP1`. Служебные файлы Visual Studio и результаты сборки исключены из Git.
