# ProjectLabaOOP1

Лабораторные работы №1–3 по объектно-ориентированному программированию на C++. Система управления складом и заказами с консольным интерфейсом магазина.

## Сборка и запуск

1. Открыть `ProjectLabaOOP1.sln` в Visual Studio 2022.
2. Установить компонент «Разработка классических приложений на C++», инструментарий MSVC v143 и Windows SDK.
3. Выбрать конфигурацию `Release` и платформу `x64`.
4. Собрать решение и запустить `ProjectLabaOOP1`.

## Лабораторная работа №1

- Абстрактный `Product` и категории `Electronics`, `Clothing`, `Food`.
- Товары `Smartphone`, `Laptop`, `TShirt`, `Jacket`, `Milk`, `Bread` и шесть фабрик.
- Атрибуты `Price`, `Quantity`, `Weight` с проверкой значений.
- `Warehouse` с глубоким копированием, правилом пяти и переносом товаров.
- Собственные обычный и константный итераторы.
- `LoggingProxy` для регистрации операций.
- Демонстрационные сценарии и проверки ошибок в `main.cpp`.

## Лабораторная работа №2

- `ProductType` и паттерн «Легковес» для общих характеристик товаров.
- `Order` с позициями заказа доставкой акциями и проверкой переходов статуса.
- Три способа доставки: курьер самовывоз и почта.
- Четыре акции: процентная скидка cashback бесплатная доставка и подарок.
- Паттерн «Стратегия» через интерфейсы `Delivery` и `Discount`.
- `DeliveryProxy` с проверкой региона и веса логированием и кэшем стоимости.
- Паттерн «Наблюдатель» через `IObserver` и `IObservable`.
- `OrderManager` с лимитами активных заказов учётом клиентов оборота за период и бонусного баланса.
- Операторы `order + discount` и `delivery << order` и вывод заказа через `std::ostream`.
- Глубокое копирование и перемещение заказов и менеджера с восстановлением подписок.
- Позиции заказа доступны снаружи только для чтения через `shared_ptr<const Product>`.

Примеры второй работы находятся в `main.cpp` в том числе в функциях `demonstrateOrderManager` и `demonstrateCopyAndMove`.

Исходники находятся в папке `ProjectLabaOOP1`. Служебные файлы Visual Studio и результаты сборки исключены из Git.

## Лабораторная работа №3

После демонстраций первых двух лабораторных программа принимает команды магазина. Склад магазина начинается пустым. Команда `help` показывает синтаксис. Для завершения ввода в консоли Windows нажми Ctrl+Z и Enter.

При создании заказа магазин резервирует по одной единице каждого указанного товара, фиксирует запрос на оплату и планирует доставку. Подтверждение списывает оплату. Отмена освобождает резерв, а отправка списывает товар. Учебный баланс клиента составляет 1 000 000 ₽. Команда добавления товара задаёт вес 1 кг на единицу.

### Сценарии

Эти команды вводятся по порядку за один запуск.

**1. Добавление товаров**

```text
add product Smartphone "iPhone 15" 100000 5
add product Laptop "MacBook Pro" 200000 3
show products
```

Смартфон и ноутбук получают ID 1 и 2.

**2. Создание и оплата заказа**

```text
create order "Иван" 1,2 courier
confirm payment 1
show orders
```

Первый заказ переходит в `Paid`. Сумма с доставкой составляет 300 500 ₽.

**3. Изменение цены и остатка**

```text
change price 1 90000
change quantity 1 -2
show products
```

Цена смартфона становится 90 000 ₽. Две единицы доступны, одна в резерве.

**4. Отмена и отправка заказа**

```text
create order "Анна" 2 pickup
cancel order 2
ship order 1
show statistics
```

Второй заказ отменён, первый отправлен. Оборот составляет 300 500 ₽.

**5. Проверка резерва**

```text
create order "Иван" 1 post
show products
remove product 1
cancel order 3
show products
show statistics
```

Склад отклоняет удаление зарезервированного смартфона. После отмены заказа доступны две единицы и резерв равен нулю.

### Вывод

Через консоль можно управлять товарами, оформлять заказы и проверять их статусы. Прогоны подтвердили, что товары списываются при отправке, а при отмене освобождается резерв и возвращается оплата.
